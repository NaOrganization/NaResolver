# UniResolver

UniResolver is a C++20, header-only resolver and invocation layer for the Windows IL2CPP runtime. It binds the IL2CPP API exported by `GameAssembly.dll` and provides runtime class, field, method, and closed-generic resolution for SDKs generated by UniDumper.

[中文](README.md) · [Macro and usage wiki (Chinese)](Wiki.md) · [Example project](example)

## Features

- Uses C++ SDK declarations generated by UniDumper directly.
- Lazily resolves and caches assemblies, types, and metadata-token methods.
- Invokes methods through `il2cpp_runtime_invoke`, including instance and virtual calls.
- Converts between `std::string` and IL2CPP `String` values.
- Supports static fields, nested and value types, name relocation, and closed generics.

## Requirements

- Windows and MSVC.
- C++20 (the example targets Visual Studio 2022 / `v143`).
- An IL2CPP target with `GameAssembly.dll` loaded.

## Quick start

1. Add `UniResolver.h`, `VmApi.h`, and `KrOr.h` to your include directory.
2. Enable C++20 and include UniResolver plus the SDK generated by UniDumper.
3. Call `UniResolver.Setup()` before using any generated wrapper.

```cpp
#include "UniResolver.h"
#include "UniDumperSdk.h"

void PrintVersions()
{
	if (!UniResolver.Setup())
	{
		return;
	}

	const std::string unityVersion =
		UnityEngine::Application::get_unityVersion();
	const std::string gameVersion =
		UnityEngine::Application::get_version();

	UniResolver.Destroy();
}
```

The DLL example separates integration code in [main.cpp](example/main.cpp) from a small UniDumper-generated SDK excerpt in [UniDumperSdk.h](example/UniDumperSdk.h). Metadata tokens vary by target version, so generate the SDK from the exact build you are working with.

See the [Wiki](Wiki.md) for every public declaration macro and detailed usage examples.
